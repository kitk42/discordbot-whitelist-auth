## A. Minecraft サーバーとプレイヤーID

**A1. サーバーの種類とバージョン**
Vanilla / Paper / Spigot / Fabric / Forge などの種類と、Minecraft のバージョンを教えてください。
回答:Vanilla 26.3

**A2. オンラインモード（正規版の認証）**
`server.properties` の `online-mode` は `true` ですか？
`false` の場合、whitelist の仕組みと Bot での ID チェックの方法が変わります。
回答:online-mode=true

**A3. 統合版（Bedrock）プレイヤー**
Geyser などを使って統合版のプレイヤーを受け入れる予定はありますか？
回答:No

**A4. 申請時のプレイヤーID チェック**
申請を受け付けた時点で、Mojang API を使って「その Minecraft ID が実在するか」を確認しますか？
存在しない ID の申請や打ち間違いを、管理者に届く前に弾けます。
推奨: 確認する
回答:No

**A5. RCON の設定**
RCON はもう有効になっていますか？
Bot はサーバーと同じ VM で動かすので、接続先は `localhost` にできます。その場合、RCON のポート（25575）は Azure の NSG で外部に公開しない想定です。
回答:RCONは未設定です。ポートを外部に公開しない方針を想定しています。
