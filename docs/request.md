# Discord Bot 要望メモ

> 大まかな要望を書き込んでください。未定の項目は空欄や「未定」のままで構いません。
> これをもとに要件定義と作業環境の構成を詰めていきます。

## 1. 目的・背景

- 何のための Bot か:minecraftサーバーを運営するにあたって、whitelistにプレイヤーidを自動追加するdiscordbotを作りたい。
- 解決したい課題:サーバーコンソール内でwhitelist addコマンドを使用してプレイヤーを登録する手間を省きたい。

## 2. 「ホワイトリスト認証」の内容

- 何をホワイトリストで管理するか（例: Discord ユーザー、外部サービスのアカウント、ゲームサーバーの参加者 など）:discordサーバー内のminecraft javaサーバー参加者
- 認証の流れのイメージ（誰が・何をして・どうなるか）:
      １．参加者が認証チャンネルでプレイヤーIDをスラッシュコマンドで送信する→管理チャンネルに情報（申請した人:プレイヤーID）が送信される。
      ２．管理者が管理チャンネル（管理者以外閲覧不可）で承認or拒否をボタン操作で行うと、サーバーに情報が送信され、rconでwhitelist追加コマンドを実行される。
- 認証成功時に起きること（例: ロール付与、外部サービスへの登録）:discordでロール付与は行わない。入力したuserIDがminecraft serverのwhitelistに登録される。
- 認証失敗・取り消し時に起きること:荒らし防止として、24時間以内に/whitelistコマンドを送信できるのは5回までとする。whitelist取り消しの動作をdiscord botから行うかは未定。

## 3. 欲しい機能

| 機能 | 概要 | 優先度（高/中/低） |
|---|---|---|
| /whitelist <ユーザーID> | 管理チャンネルに情報を送信する | 必須 |
| 管理チャンネルでの認証 | 管理チャンネル内のボタン操作で承認or拒否を決める | 必須 |

- スラッシュコマンドの希望（コマンド名・使える人）:"/whitelist <ユーザーID>" 参加希望者全員
- 管理者向けの操作（追加・削除・一覧 など）:上記のコマンドを認証チャンネルでユーザーが送信すると、管理チャンネルで管理者がボタンによる承認、拒否を行う

## 4. 利用規模・運用

- 導入するサーバー数 / 想定ユーザー数:サーバー１、ユーザー５人程度
- 管理者・運用者は誰か:私（個人）
- 稼働させる場所（自宅PC、VPS、クラウド など）:Azure VM上のUbuntu 24.04 LTS（server VMに同居させる）
- 24時間稼働が必要か:必要

## 5. 技術面の希望

- 言語・ライブラリ（例: TypeScript + discord.js、Python + discord.py、こだわりなし）:Python + discord.py
- データの保存先（例: SQLite、JSON ファイル、外部DB、こだわりなし）:必要であればSQLite
- 連携する外部サービス・API:https://discord.com/developers/applications/
- 開発環境（Dev Container、Docker、ローカル直など）:提案をお願いします
